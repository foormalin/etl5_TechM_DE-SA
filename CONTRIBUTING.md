# Contributing

Изменения выполняются небольшими вертикальными пакетами. Для каждой публичной API
операции обновляется OpenAPI, для события — Avro schema и compatibility fixture.

Перед коммитом:

```bash
pnpm check
pnpm build
```

Не размещайте бизнес-сущности в shared package и не обращайтесь к БД соседнего
сервиса. Архитектурное изменение оформляется ADR.
