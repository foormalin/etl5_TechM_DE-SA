# Сценарий демонстрации

1. Открыть buyer workspace, найти товар и добавить две позиции в корзину.
2. Оформить закупку и показать созданный Purchase/Orders.
3. Переключиться в seller workspace, открыть товары, склады и заказ.
4. Провести разрешённый переход статуса заказа.
5. Создать обращение покупателя.
6. Переключиться в TechM workspace и открыть аудит/модерацию.
7. Показать `/api/health`, идемпотентный повтор checkout и RFC 9457 ошибку.
8. В полном Compose-контуре показать Keycloak, Kafka UI и Grafana trace.
