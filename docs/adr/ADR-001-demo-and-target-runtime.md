# ADR-001: demo runtime и целевая микросервисная платформа

Статус: принято, 28.07.2026.

## Контекст

Публичная portfolio-демонстрация должна работать без дорогой постоянной
инфраструктуры, а системная документация требует FastAPI, PostgreSQL, Kafka,
Keycloak и отдельные сервисные БД.

## Решение

Поддерживать два совместимых контура. Cloudflare Worker + D1 является
облегчённым демонстрационным runtime. Docker Compose является локальным target
runtime и сохраняет сервисные границы, контракты и инфраструктурные зависимости.

## Последствия

Demo не считается production-развёртыванием и использует тестовую ролевую
сессию. Перенос функции в target runtime обязан сохранить OpenAPI, error codes,
idempotency semantics и события. Реальные PSP, carrier и ЭДО остаются за
адаптерами, как предусмотрено baseline документацией.
