# Security policy

Репозиторий использует только синтетические данные. Не коммитьте токены, реальные
пароли, персональные данные или платёжные реквизиты.

Сообщения об уязвимостях следует передавать владельцу репозитория приватно, с
описанием impact, шагов воспроизведения и затронутой версии. Для API обязательны
проверки issuer/audience, active company, object ownership, input limits,
idempotency и structured logging без секретов.
